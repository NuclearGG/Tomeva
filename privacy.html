Tomeva

Privacy Policy

Last updated: 2 October 2026

This policy covers the Tomeva website at nucleargg.github.io/Tomeva and explains who is responsible for data when you use the Tomeva software. Tomeva is an open-source project maintained by NuclearGG.

In short

  • The website has no accounts, forms, cookies, advertising or analytics.
  • We do not collect, store or sell your personal information through this website.
  • Library data created with the Tomeva software lives in your own institution's Firebase project, not on any server run by the Tomeva project.

What happens when you visit the website

The site is a static page hosted on GitHub Pages. We do not run a server or database for it and we do not receive visitor logs. Your browser does contact the following third parties directly, and they may process your IP address and basic browser details under their own policies:

  • GitHub hosts the pages and serves release downloads. The page also asks the GitHub API for the latest release so the download button points to the newest Control Center file.
  • Google Fonts supplies the typefaces on the home page.
  • cdnjs (operated by Cloudflare) supplies the GSAP and Three.js animation libraries.

The Privacy Policy and Terms pages load no third-party resources.

Cookies and local storage

The website does not set cookies and does not save anything in your browser's local storage. Third-party services above may set their own, which we do not control.

Downloading the software

Downloads come from GitHub Releases. GitHub may record download activity as described in the GitHub Privacy Statement. Clicking the download button is the only thing that starts a download.

Data in the Tomeva software

Tomeva is designed so that each institution deploys its own Firebase project and controls its own authentication, database, configuration and users. That means:

  • Your institution decides what data is collected, who can access it and how long it is kept.
  • Your institution is responsible for the data it holds about librarians, staff, students and teachers, and for following the privacy and student-data laws that apply to it.
  • Google processes that data as your Firebase provider under Google's own terms and privacy policy.
  • The Tomeva project does not receive your institution's records, Recovery Kits, service-account keys or Firebase credentials.

Control Center and the other apps contact GitHub to download packages and check for updates, so GitHub can see those requests.

Children

The website is not directed at children and collects no personal information from anyone. Institutions that use the software with students should make sure their setup meets the rules that apply to them, including any parental consent requirements.

Changes to this policy

If this policy changes, the updated version will be posted here with a new date.

Contact

Questions about this policy can be raised as an issue at github.com/NuclearGG/Tomeva/issues.
