📌 About this System

This is an offline-first library management system built for your school library. It runs entirely on your local computer — no internet required. Data is stored locally and can be backed up at any time using the backup function above.

Version: 1.0  |  Stack: HTML · CSS · JS (Electron-ready)  |  Database: localStorage (swap for SQLite in Electron)
