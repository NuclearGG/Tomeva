PROTECT YOUR INSTALLATION
Control Center Recovery Kit
Restore your institution settings on a replacement computer. Keep an encrypted copy off this computer and store the password separately with the institution.
No recovery kit created
Verification checks encryption, integrity, institution settings and supported format without changing this installation. Passwords are never saved or sent to Tomeva. Rotation does not invalidate older copies: securely dispose of those you no longer need.
Recover using an existing Firebase project
If the kit is lost, enter the project's existing public Firebase configuration and staff domain. Save it, then export replacement packages. Sign in using an authorized staff account in Admin to access the existing institution data. Do not replace your project's existing rules as part of recovery.
This kit contains bootstrap settings, not the library database. Back up the Librarian workstation database separately.
