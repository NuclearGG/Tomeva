The principle Ownership before convenience

“Your library should keep working even when somebody else’s server does not.”
Local

Circulation stays at the desk

Librarian records loans, returns, fines, and damage in a local SQLite database, then synchronizes when a connection returns.

Private

Records stay in your project

Each institution controls authentication, Firestore, hosting, staff access, and retention. Tomeva does not receive library records.

Open

Code and packages can be checked

The source is MIT licensed. Release assets include checksums, update metadata, and separate compatibility lines.

Plain answers Before you install

What schools usually ask.

Is Tomeva free?
Yes. The source is available under the MIT license. Your own Firebase usage remains subject to Google’s service quotas.
Does the library desk work offline?
Yes. Daily circulation in Librarian continues locally. Internet is needed for setup, Admin access, downloads, and synchronization.
Who owns the data?
Your institution. Tomeva is deployed against your Firebase project, accounts, rules, database, and hosting.
Do users need Node.js or Git?
No. Users download Control Center. Developer tools are only required when building or changing the source.
Are the installers signed?
Current community builds are unsigned, so Windows may ask for confirmation before running them. Checksums are published with each release.
