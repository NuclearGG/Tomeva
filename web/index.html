Library software your school fully owns.

Tomeva is free, open-source library management for schools, institutions and small libraries. Staff check books in and out even without internet, and your data stays in your own Firebase project.

Download for Windows 10/11 Windows 7 / 8.1

Windows x64. Version latest, MIT licensed. View the source.

Four apps, one library

You install Control Center first. It sets up the rest for your institution.

Control Center

For whoever sets things up

Configures Firebase, generates rules and install packages, exports the student site and manages recovery kits.

Librarian

For the library desk

Books, students, loans, returns and fines. Backups and a workstation PIN included. Circulation works offline.

Admin

For authorised staff

Manage student access, provision or revoke kiosks, review synced data and approve updates.

Student Portal

For students and teachers

A website where students browse availability and send requests, hosted wherever you choose.

From download to first loan

Control Center walks you through it. You do not need Node.js, Git or manual downloads.

  1. Create a Firebase project

    Register a web app, create Firestore and enable Google, Anonymous and Email/Password sign-in.

  2. Configure Control Center

    Enter your Firebase web config and your staff email domain.

  3. Publish the generated rules

    Paste the rules file Control Center creates into Firestore and add the included indexes.

  4. Host the Student Portal

    Control Center exports the site. Upload it over HTTPS and authorise the domain in Firebase.

  5. Install Admin and Librarian

    Control Center checks each download against its SHA-256 checksum, then adds your settings locally.

  6. Back up

    Create an encrypted Recovery Kit, and use Librarian's backup command for circulation records.

Questions

Is Tomeva free?

Yes. It is open source under the MIT license. Firebase quotas apply to your own Firebase project.

Does it work offline?

Daily circulation in Librarian does. Internet is needed for first downloads, Firebase setup, Admin sign-in and sync.

Which operating systems are supported?

Windows 10/11 x64 has its own installer, and there is a separate legacy installer for Windows 7, 8 and 8.1 x64. Linux and macOS packages are not included in the current release.

Who owns the data?

Your institution. Each school deploys Tomeva on its own Firebase project and controls its own accounts, database and users.

Do I need Node.js or Git?

No. Those are only for developers building from source. The installer includes everything it needs.
